# עוקב מניות חכם

אפליקציית ווב מתקדמת (PWA) שעוקבת אחרי רשימת מניות שאתה מגדיר (ארה"ב + בורסת תל אביב), מנתחת אותן על בסיס שילוב של ניתוח טכני, ניתוח פונדמנטלי וסנטימנט חדשות, ומתריעה אליך **ישירות לנייד** (Push אמיתי, לא טלגרם) כשמניה מגיעה לפוטנציאל גבוה או שמתקיים איתות כניסה/יציאה. מיועדת לסטייל מסחר סווינג (ימים-שבועות), לא למסחר יומי.

⚠️ **גילוי נאות**: הכלי נועד למידע ולסינון בלבד. הוא **לא** ייעוץ השקעות, לא מבטיח רווח, ואינו מחליף שיקול דעת עצמאי. כל החלטת מסחר היא באחריותך המלאה.

## מה יש כאן

- **סריקה אוטומטית** של רשימת המעקב שלך כל כמה שעות (מוגדר, ניתן לשינוי).
- **ניקוד משוקלל 0-100** לכל מניה, המשלב:
  - ניתוח טכני (RSI, MACD, ממוצעים נעים, בולינגר, תמיכה/התנגדות, נפח מסחר)
  - ניתוח פונדמנטלי (P/E, P/B, חוב/הון, צמיחה, רווחיות, יעד מחיר אנליסטים)
  - סנטימנט חדשות (ניתוח כותרות חדשות אחרונות)
- **איתותי כניסה/יציאה** מבוססי-חוקים לסווינג טרייד, כולל מעקב רווח/הפסד אם ציינת שאתה מחזיק בפועל.
- **התראות Push אמיתיות לנייד/דסקטופ** - מותקן כאפליקציה למסך הבית (PWA), בלי חנות אפליקציות, בלי טלגרם, בלי תלות בצד שלישי.
- תומך במניות אמריקאיות (`AAPL`, `MSFT`...) ומניות תל אביב (עם סיומת `.TA`, למשל `TEVA.TA`, `POLI.TA`, `ICL.TA`).

## דרישות

- Python 3.10+
- חיבור אינטרנט רגיל (השרת שולף נתונים מ-Yahoo Finance - ציבורי, בלי מפתח API)
- **HTTPS** כדי שההתראות Push יעבדו בדפדפן (זו דרישת אבטחה של הדפדפנים עצמם, לא של האפליקציה). לפיתוח/בדיקה מקומית `localhost` גם נחשב "בטוח" ועובד בלי HTTPS.

## התקנה

```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # ואופציונלית לערוך ערכים
```

## הרצה מקומית (לבדיקה, ב-localhost)

```bash
cd backend
python run.py
```

האפליקציה תעלה על `http://localhost:8000`. פתח בדפדפן (Chrome/Edge מומלץ לבדיקה), הוסף מניה למעקב, ולחץ "סרוק עכשיו". על `localhost` ניתן גם להפעיל את כפתור ההתראות (🔔) ולבדוק עם "שלח התראת בדיקה" - זה עובד גם בלי HTTPS אמיתי כי הדפדפן מתייחס ל-localhost כסביבה בטוחה.

## התקנה כאפליקציה בנייד + התראות אמיתיות

כדי שההתראות יעבדו **בטלפון** (ולא רק בדפדפן שבו האפליקציה רצה), האפליקציה חייבת לרוץ תחת כתובת HTTPS ציבורית, והטלפון צריך לפתוח אותה ולהתקינה למסך הבית:

1. **פרסם את השרת** בכתובת HTTPS ציבורית (ראה "פריסה לשימוש 24/7" למטה).
2. בטלפון, פתח את הכתובת בדפדפן:
   - **אנדרואיד (Chrome)**: תפריט ⋮ → "הוסף למסך הבית" / "התקן אפליקציה".
   - **iPhone (Safari, iOS 16.4+)**: כפתור השיתוף 🔺 → "הוסף למסך הבית". **חשוב**: ב-iPhone חובה לפתוח את האפליקציה שהותקנה למסך הבית (לא את הדפדפן) ורק משם ללחוץ על כפתור ההתראות 🔔 - זו מגבלה של אפל, לא של האפליקציה.
3. לחץ על 🔔 בתוך האפליקציה המותקנת, אשר את בקשת ההרשאה, ולחץ "שלח התראת בדיקה" כדי לאמת שהכל עובד.

## בדיקה מהירה עם HTTPS זמני (ngrok)

כדי לבדוק את זרימת ה-Push האמיתית לפני שאתה פורס לשרת קבוע, אפשר לחשוף את הריצה המקומית שלך זמנית ל-HTTPS:

```bash
# בטרמינל אחד:
cd backend && python run.py

# בטרמינל שני (התקנה חד-פעמית: https://ngrok.com/download):
ngrok http 8000
```

ngrok ייתן כתובת `https://xxxx.ngrok-free.app` - פתח אותה בנייד, התקן למסך הבית, והמשך כמו לעיל. שים לב: כתובת ה-ngrok החינמית מתחלפת בכל הפעלה.

## פריסה לשימוש 24/7

הריצה המקומית שלך (או כל sandbox זמני) לא ממשיכה לרוץ כשהמחשב כבוי - כדי לקבל התראות באמת "ברקע" צריך שהשרת ירוץ כל הזמן, אצלך. כמה אפשרויות נפוצות ופשוטות:

- **VPS זול** (DigitalOcean/Hetzner/AWS Lightsail וכו'): התקן Python, שכפל את הפרויקט, הרץ עם `gunicorn` מאחורי `nginx` + תעודת HTTPS חינמית מ-Let's Encrypt (`certbot`). זו הדרך הכי אמינה ל"תמיד דלוק".
  ```bash
  pip install gunicorn
  gunicorn -w 1 -b 127.0.0.1:8000 "app:create_app()"
  ```
  (שימי לב ל-`-w 1` - עובד אחד בלבד, כי הסקנר והמצב נשמרים בזיכרון של תהליך יחיד; זה מספיק לשימוש אישי).
- **Render.com / Railway.app**: מתאימים ל-Flask app קטן, יש שכבה חינמית/זולה, HTTPS מובנה. חבר את ה-repo, הגדר `Start Command`: `gunicorn -w 1 -b 0.0.0.0:$PORT "app:create_app()"` מתוך תיקיית `backend`. **למדריך Render מלא, צעד-אחר-צעד (כולל קובץ `render.yaml` מוכן), ראה [DEPLOY.md](DEPLOY.md).**
- **מחשב אישי / Raspberry Pi בבית**: אפשר, אבל תצטרך HTTPS ציבורי (כמו Cloudflare Tunnel) כדי שהטלפון יוכל להתחבר גם מרשת סלולרית.

בכל אפשרות - קובץ ה-`data/` (מסד הנתונים המקומי + מפתחות ה-VAPID) הוא הזיכרון היחיד של האפליקציה; אל תמחק אותו אם אתה מעביר שרת, אחרת תצטרך להתחבר להתראות מחדש.

## הגדרות וכוונון (`backend/.env`)

| משתנה | מה הוא עושה |
|---|---|
| `SCAN_INTERVAL_MINUTES` | כל כמה דקות סורקים את כל רשימת המעקב (מומלץ 60-180 לסווינג) |
| `SCAN_ACTIVE_HOUR_START/END` | טווח שעות ביום שבו מתבצעות סריקות |
| `WEIGHT_TECHNICAL/FUNDAMENTAL/SENTIMENT` | משקל כל מרכיב בניקוד המשוקלל (צריך להסתכם ל-1.0) |
| `HIGH_POTENTIAL_SCORE_THRESHOLD` | מעל איזה ניקוד (0-100) נשלחת התראת "פוטנציאל גבוה" |
| `ALERT_COOLDOWN_HOURS` | כמה שעות מינימום בין שתי התראות מאותו סוג על אותה מניה, כדי לא להציף |

ניתן גם לכוונן ספי אינדיקטורים טכניים (RSI, MACD, ממוצעים) בקובץ `backend/app/config.py`.

## מבנה הפרויקט

```
backend/
  app/
    market_data.py       # שליפת נתונים מ-Yahoo Finance (מחירים, פונדמנטלס, חדשות)
    analysis/
      indicators.py       # RSI, MACD, ממוצעים, בולינגר, תמיכה/התנגדות
      fundamentals.py      # ניקוד פונדמנטלי
      sentiment.py         # ניקוד סנטימנט חדשות
      scoring.py            # ניקוד משוקלל + מנוע איתותי כניסה/יציאה
      engine.py              # מארגן הכל לניתוח אחד מלא למניה
    push/
      vapid.py             # מפתחות VAPID + חתימת JWT
      webpush.py            # הצפנת הודעות Push (RFC 8291) ושליחתן
      service.py             # שכבת נוחות: broadcast להתראות לכל המכשירים
    scheduler.py            # לופ סריקה ברקע + קבלת ההחלטה מתי לשלוח התראה
    routes/api.py            # ה-API שה-frontend מדבר איתו
    db.py                     # שכבת SQLite (רשימת מעקב, מנויי Push, לוג התראות)
  run.py                       # נקודת הכניסה להרצה מקומית
frontend/
  index.html / app.js / style.css   # ה-PWA עצמו
  manifest.json / service-worker.js # מה שהופך אותו לניתן-להתקנה + מקבל Push ברקע
```

## מגבלות ידועות

- הנתונים מגיעים מ-Yahoo Finance הציבורי (כמו שמשתמשת בו הספרייה הפופולרית `yfinance`) - זה חינמי אבל לא רשמי, ולעיתים נדירות עלול להיות מוגבל/מושהה זמנית. אם התקנת גם את `yfinance` (מומלץ, כלול ב-requirements.txt) האפליקציה תשתמש בו כברירת מחדל - הוא מתמודד טוב יותר עם הגנות אנטי-בוט של יאהו.
- ניתוח הסנטימנט מבוסס על כותרות חדשות בלבד (לא ניתוח מלא של תוכן כתבות).
- זו לא המלצת השקעות - האיתותים הם חוקים טכניים פשוטים, לא מודל חזוי.
